# Брендбук Кейса №2 — «TaskFlow»

Учебная айдентика, разработанная для этого кейса. Чужие логотипы, платные шрифты
и сторонние графические ассеты не использовались.

## Название
**TaskFlow** — поток задач. Нейтральное рабочее имя для внутреннего инструмента компании.

## Знак
Собственная геометрия: три горизонтальные «дорожки» задач разной длины и зелёная точка
завершения справа. Рисуется инлайн-SVG в коде (`src/app/layout.js`, `src/app/login/page.js`),
отдельных файлов-ассетов нет — знак весит ноль байт и не требует загрузки.

## Палитра

| Токен | HEX | Где используется |
|---|---|---|
| `ink` | `#14213D` | тёмно-синий: шапка знака, основной текст, кнопка при наведении |
| `sky` | `#2F6BFF` | акцент: первичные кнопки, ссылки, статус «в работе» |
| `mint` | `#17B890` | успех: статус «выполнена», метка авто-распределения |
| `amber` | `#F6A609` | внимание: статус «на проверке» |
| `rose` | `#E5484D` | ошибка: высокий приоритет, просрочка, сообщения об ошибках |
| `paper` | `#F6F8FC` | фон страниц |

Контраст основного текста (`ink` на `paper`) — выше 12:1, кнопки (`белый` на `sky`) — выше 4.5:1,
то есть требования WCAG AA по тексту выполняются.

## Типографика
Системный шрифтовой стек (`ui-sans-serif, system-ui, Segoe UI, Roboto, Arial`).
Внешние шрифты намеренно не подключались: приложение должно открываться и без интернета,
а лицензионные вопросы по шрифтам не возникают вовсе.

## Тон интерфейса
Короткие подписи, глаголы в повелительном наклонении («Создать задачу», «Применить»).
Никаких восклицательных знаков и «вау»-формулировок — это рабочий инструмент.

## Что НЕ входит
Логотип клиента, фирменные цвета клиента, иллюстрации, иконочный набор.
При реальном заказе всё это берётся из брендбука клиента и оценивается отдельно.
