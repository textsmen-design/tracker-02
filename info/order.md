**Реальная ссылка (проверена 18.09.2026):** https://freelance.ru/projects/razrabotka-veb-prilozheniya-next-dlya-avtomatizacii-upravleniya-zadachami-1656833.html
**Название заказа:** «Разработка Веб-приложения на Next.js для автоматизации управления задачами и сотрудниками»

## Карточка заказа
- **Задача клиента:** веб-приложение для автоматизации процессов управления задачами, проектами и сотрудниками внутри компании: учёт задач, распределение обязанностей, контроль сроков и прогресса, упрощение внутренних коммуникаций. «Что-то среднее между личным планировщиком задач и…».
- **Функциональность (ИИ-агрегированное описание на странице):** регистрация и авторизация; создание и управление задачами; назначение задач сотрудникам; отображение статуса выполнения; фильтрация задач; панель администратора для управления пользователями; интеграция модуля ИИ для автоматической категоризации и распределения задач.
- **Технологии (требование клиента):** Next.js + Tailwind CSS (фронтенд), Node.js с Express/Fastify (бэкенд), PostgreSQL (БД), Supabase Auth (аутентификация), OpenAI API (ИИ-модуль); деплой Vercel (фронтенд) + Render/Heroku (бэкенд).
- **Срок:** 30 дней.
- **Бюджет:** по договорённости. **Оплата:** по договорённости.
- **Категория:** Веб-разработка и ИТ.
- **Опубликовано:** 08.01.2026. **Статус объявления:** задание в архиве (набор закрыт).

## Примечания по честности
- Полный текст заказа требует входа. На странице есть и исходный срез, и «Оптимизировано и агрегировано ИИ» — сохранены оба (в `order_text.md`).
- Стек урока (чистый HTML/CSS/JS MVP) проще клиентского; для учебного MVP возьмём функцию ролей (админ/исполнитель) и назначения задач, а не весь стек.
