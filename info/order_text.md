Агрегированное ИИ-описание на странице (вставлено в сервисом freelance.ru):
```
Нам нужно разработать веб-приложение на Next.js для автоматизации управления задачами и
сотрудниками в компании. Приложение должно включать функции регистрации и авторизации
пользователей, создания и управления задачами, назначения задач сотрудникам, отображения
статуса выполнения, фильтрации задач, а также иметь панель администратора для управления
пользователями. Также требуется интеграция модуля ИИ для автоматической категоризации и
распределения задач.

Используемые технологии: Next.js с Tailwind CSS для фронтенда, Node.js с Express или
Fastify для бэкенда, PostgreSQL для базы данных, Supabase Auth для аутентификации, и
OpenAI API для ИИ-модуля. Приложение должно быть развернуто на Vercel для фронтенда и
Render или Heroku для бэкенда.

Для реализации этого задания потребуются навыки в разработке на Next.js и Tailwind CSS,
опыт работы с Node.js и Express/Fastify, знание PostgreSQL для работы с базами данных,
понимание аутентификации с Supabase Auth, опыт развертывания приложений на Vercel и
Render/Heroku, а также навыки интеграции ИИ с использованием OpenAI API.
```
