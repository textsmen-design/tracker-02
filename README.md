## Что умеет

- вход и выход, серверные сессии, закрытые страницы;
- роли: администратор и сотрудник;
- задачи: создание, назначение исполнителя, статусы, срок (необязателен), приоритет;
- фильтры: статус, категория, исполнитель, поиск по названию;
- подсветка просроченных задач;
- **модуль авто-категоризации и авто-распределения** задач;
- панель администратора: сотрудники, нагрузка, добавление, отключение;
- история изменений задачи.

## Стек

Next.js 16 (App Router) + Tailwind CSS + PostgreSQL 16, драйвер `pg`, пароли — bcrypt.

Отклонения от стека заказа зафиксированы в `info/tz.md` §8. Коротко:
вместо отдельного Express-сервиса — серверные функции самого Next.js;
вместо Supabase Auth — собственная сессия (нужен аккаунт клиента);
вместо OpenAI API — детерминированный офлайн-классификатор (ключ платный и принадлежит клиенту).
**Модуль категоризации — не нейросеть**, и это прямо написано в интерфейсе.

## Запуск

```bash
# 1. база
createdb -h 127.0.0.1 -U postgres taskflow
psql -h 127.0.0.1 -U postgres -d taskflow -f db/schema.sql

# 2. зависимости и демо-данные
cd app
npm install
node scripts/init_db.js

# 3. сборка и запуск
npm run build
npm start            # http://localhost:3000
```

Параметры БД читаются из переменных окружения `PGHOST`, `PGPORT`, `PGUSER`,
`PGPASSWORD`, `PGDATABASE` (по умолчанию — локальный postgres и база `taskflow`).
